<h2 id="ch1">1. 项目总览</h2>

<h3 id="sec11">1.1 定位与架构</h3>

- 定位为**全品类一站式综合购物平台**，覆盖数码家电、服饰美妆、食品生鲜、家居百货等日常消费场景；「青禾」为抽象品牌名，翠绿主题主色 `#10b981`。
- **平台型三方结构**（M6 重构）：平台管理员（审核入驻/全局运营）+ 入驻商家（商品/订单/统计，需平台审核）+ 顾客（购物/下单/支付/评价/秒杀/优惠券）。
- 交易链路闭环：浏览 → 购物车 → 结算下单 → 支付（支付宝/微信/模拟）→ 发货 → 收货 → 评价 → 退款/取消/超时关单。
- 工程化：Docker Compose 一键起、GitHub Actions CI、Prometheus + Grafana 监控、JaCoCo 覆盖率、前端 Vitest + ESLint。

<h3 id="sec14">1.4 角色与权限</h3>

| 角色 | role | 注册方式 | 入口 | 权限要点 |
| --- | --- | --- | --- | --- |
| 顾客 | `USER` | 注册页选「顾客」即生效 | 店铺前台 | 购物/下单/支付/评价/退款申请/优惠券/秒杀/地址 |
| 入驻商家 | `MERCHANT` | 注册页选「商家」+ 店铺名 → 平台审核 | `/merchant` 工作台 | 仅操作本店商品/订单；店铺 `status=ACTIVE` 才可经营 |

- 商家审核状态：`PENDING`（待审）→ `ACTIVE`（通过）/ `REJECTED`（驳回+原因）/ `DISABLED`（禁用）。
- 顾客账号可通过个人中心「我要开店」升级为商家：前端 `Profile.vue` 入驻面板 + 申请弹窗 → 后端 `POST /api/merchant/apply`（幂等，复用 `MerchantService.apply`）；审核通过后 `/info` 自动将会话角色刷新为 `MERCHANT`，无需重新登录即可进入 `/merchant` 工作台。

<h2 id="ch2">2. 快速开始</h2>

<h3 id="sec21">2.1 环境要求</h3>

JDK 1.8+（本机 JDK 21 可运行）、Maven 3.6+、Node 16+、MySQL 8（utf8mb4）、Redis 5+；Docker 20.10+（可选）。

<h3 id="sec22">2.2 数据库初始化与迁移</h3>

- **全新库**：`mysql -uroot -p1234 --default-character-set=utf8mb4 < backend/index.sql`（⚠️ 必须带 utf8mb4，否则中文 nick_name 报 Data too long）。
- **存量库升级**：依次执行 `backend/sql/migration/` 下全部 `v*.sql`（幂等可重复）。完整清单见[附录 B](#appB)：v1.1 安全 / v1.2 种子管理员 / v1.3 购物车+订单字段 / v1.4 品牌+DECIMAL（两个）/ v1.5 地址 / v1.6 评价+库存流水 / v1.7 存量图本地化 / v1.8 优惠券 / v1.9 秒杀 / v2.0 平台化。

<h3 id="sec23">2.3 后端构建与启动</h3>

```bash
# 本机 Maven：/c/Users/ASUS/maven-3.9.16/apache-maven-3.9.16/bin/mvn.cmd
mvn.cmd -o compile           # 离线编译
mvn.cmd -o test              # 全量测试（集成用例需 MySQL+Redis 在线）
```

<h2 id="ch3">3. 数据模型</h2>

<h3 id="sec31">3.1 表清单（qinghedb）</h3>

`user` / `merchant`(M6) / `product` / `product_detail` / `order` / `cart` / `qinghe_payment_record` / `address` / `comment` / `stock_log` / `coupon`(A2) / `user_coupon`(A2) / `seckill_activity`(A3) / `seckill_order`(A3)。

<h3 id="sec32">3.2 关键表结构</h3>

- **user**：id、user_name（唯一）、pwd（BCrypt，兼容旧 MD5 过渡）、nick_name、avatar、**role**（USER/MERCHANT/ADMIN，v1.2 迁移加列）、gmt_created/gmt_modified。
- **merchant**（v2.0）：id、user_id（UK 1:1）、shop_name、shop_logo、shop_desc、**status**（PENDING/ACTIVE/REJECTED/DISABLED）、reject_reason、时间戳；idx_status。
- **product**：id（varchar32）、name、brand、**merchant_id**（NULL=平台自营）、**status**（ON/OFF，DEFAULT ON）、price DECIMAL(10,2)、purchase_num、product_intro、product_imgs（空格/分号分隔，首图缩略图）、时间戳；idx_merchant_id。
- **product_detail**：id、product_id、price DECIMAL(10,2)、size DOUBLE(8,2)、stock、时间戳。
- **order**：id、order_number（`QH+时间戳+4位序号`，Redisson AtomicLong）、user_id、**merchant_id**（冗余，下单按商品归属落库）、product_detail_id、quantity、total_price（实付=原价-优惠）、status、coupon_id、discount_amount（**NOT NULL**）、receiver_name/phone/address、时间戳；idx_order_number/user_id/merchant_id。*无 order_detail 表。*
- **cart**：user_id + product_detail_id + quantity + selected。
- **qinghe_payment_record**：order_number、channel、pay_status（PAYING/SUCCESS/FAILURE）、channel_payment_id（模拟 `SIM_`、支付宝 `ALI_`）。
- **address**：user_id、receiver_name/phone/address、is_default（首条自动默认）。
- **comment**：product_id、order_number（**唯一防重复**）、user_id、rating（1-5）、content（≤500 字）；userNickName 为展示字段（查询时按 user_id 填充，不落库）。
- **stock_log**：product_detail_id、product_id、order_number、change_type（ORDER_DEDUCT / ORDER_RESTORE / EXPIRE_RESTORE / **STOCK_SET**）、quantity（±）、before_stock/after_stock、时间戳。
- **coupon / user_coupon**：券模板（type FULL_REDUCTION/DISCOUNT、amount、**discount**（折扣率，对应前端公式 rate 语义）、maxDiscount、total、issued、status）+ 用户券（user_id、coupon_id、status UNUSED/USED/RELEASED/EXPIRED、order_number、过期时间）。
- **seckill_activity**：product_detail_id、seckill_price、total_stock、**remain_stock**（独立活动库存）、start_time/end_time、status（NOT_START/ONGOING/CLOSED/ENDED）；**seckill_order**：user_id、activity_id、product_detail_id、quantity、order_number、status（仅 CREATED/CANCELLED）、**uk_user_activity 唯一约束**。

<h3 id="sec33">3.3 订单状态机</h3>

`WAIT_BUYER_PAY`（待付款）→ `TRADE_PAID_SUCCESS`（已付款）→ `TRADE_SHIPPED`（待收货）→ `TRADE_COMPLETED`（已完成）；`WAIT_BUYER_PAY` → `TRADE_CLOSED`（取消/超时）；`TRADE_PAID_SUCCESS` → `TRADE_REFUNDING`（退款中，仅未发货）→ `TRADE_REFUNDED` / 回退 `TRADE_PAID_SUCCESS`；另有 `TRADE_PAID_FAILED`。

- 全部流转经 `OrderDAO.updateStatusWithGuard(orderNumber, expected, target)`（`WHERE status=expected` CAS）原子守卫；非法 status 由 `OrderStatus.isValid` 拒绝。
- 前端状态中文映射（`utils/format.js statusText`）：8 态全覆盖。

<h3 id="sec34">3.4 金额与编码约定</h3>

<h2 id="ch4">4. API 手册</h2>

<h3 id="sec40">4.0 通用约定与前端 API 映射</h3>

- Base URL `http://localhost:8080/api`；鉴权 Session Cookie（withCredentials）；JSON UTF-8。
- **统一响应 `Result<T>`**：`{success, code, message, data}`；分页 `Paging<T>`：`{pageNum, pageSize, totalPage, totalCount, data}`。
- **业务状态码**：200 成功 / 400 参数错误 / 401 未登录 / 403 无权限 / **429 限流** / 500 业务失败。
- ⚠️ **HTTP 语义**：全站 HTTP 恒 200，业务状态看 `Result.code`；联调判断 `grep '"code":200'`。
- **CSRF**：POST/PUT/DELETE 校验 Referer/Origin（白名单 5173/8080，生产 `CSRF_ALLOWED_ORIGINS`）；curl 必须带 `-H "Referer: http://localhost:5173/"`；两个支付回调在 exclude-paths 放行。
- **限流（@RateLimit，Redisson RRateLimiter 令牌桶）**：登录/注册 5/s；下单（add/batchAdd）/支付（create/mockPay）20/s；秒杀下单 100/s。
- **前端 API 模块映射**（`src/api/`）：user（reg/loginApi/logoutApi/checkLoginApi/updateProfileApi）、cart（addCart/updateCartQuantity/updateCartSelected/removeCart/listCart/countCart/clearSelectedCart）、product（pageQuery/listBrands/get/getProductDetails）、order（addOrder/batchAddOrders/cancelOrder/listOrders/getOrder/confirmReceipt/applyRefund）、payment（createPay/mockPay/queryPay）、coupon（claimCoupon/myCoupons/listCoupons/availableCoupons）、seckill（listSeckillActivities/getSeckillActivity/createSeckillOrder）、address（listAddress/getDefaultAddress/addAddress/updateAddress/deleteAddress/setDefaultAddress）、comment（addComment/listProductComments/getCommentSummary/getOrderCommentStatus）、file（uploadImage）、admin（getDashboard/getSalesReport/getProductList/addProduct/updateProduct/deleteProduct/getOrderList/updateOrderStatus/shipOrder/processRefund/getUserList/updateUserRole/createCoupon/listCoupons/updateCoupon/toggleCoupon/createSeckill/listSeckills/toggleSeckill/listMerchants/auditMerchant）、merchant（getMerchantInfo/listMerchantProducts/saveMerchantProduct/toggleMerchantProduct/listMerchantOrders/merchantShip/merchantProcessRefund/getMerchantStats）。
- **注册/登录为 form-urlencoded**（前端 `URLSearchParams`）；其余 POST 以各接口说明为准（多为 JSON body）。

<h2 id="ch5">5. 核心设计</h2>

<h3 id="sec51">5.1~5.11 业务设计</h3>

1. **订单状态机与 CAS 守卫**：全部流转 `updateStatusWithGuard`（`WHERE status=expected`）；订单锁释放校验 `isHeldByCurrentThread()` 防租期过期异常。
2. **并发与防超卖**：普通下单 `order:lock:{detailId}` Redisson 锁（tryLock 3s/租期 5s）+ `decreaseStock` CAS（实测 20 线程抢 5 库存恰 5 单）；秒杀三重防线（活动 remain_stock CAS → SKU 二次 CAS → uk_user_activity 唯一约束，30 线程抢 10 库存恰 10 单）。
3. **延迟关单（P2-1）**：`OrderTimeoutQueue`（RDelayedQueue）下单入队，`OrderTimeoutTask` 轮询兜底 5min，默认 30 分钟（`-Dqinghe.order.expire-minutes`）；⚠️ 勿调 `delayedQueue.destroy()`。取消/超时走 `closeAndRestoreStock`（回滚库存+流水+释放券+秒杀 rollbackIfUnpaid，`@Lazy` 打破循环依赖）。
4. **限流（P2-3）**：`@RateLimit` + AOP，RRateLimiter 令牌桶，key 前缀 `ratelimit:`；支持 `{userId}` 维度；⚠️ 无 trySetPermits（桶容量=rate）、trySetRate 幂等勿重置。
5. **支付渠道（M2-9）**：`PayChannel` 抽象（Alipay 优先 / Mock 回退 / Wechat 保留）；支付宝当面付预下单、微信 Native；回调验签+`updateStatusIfWaitPay` 幂等；密钥支持 PEM 内容/文件、PKCS1/PKCS8。
6. **优惠券（A2）**：user_coupon 状态机 UNUSED→USED（CAS 绑单）→RELEASED（取消/拒退复位）；已支付退款不退券；领取防超发（incrementIssued + uk_user_coupon）。
7. **秒杀（A3）**：活动独立库存预扣+用户级锁+事务；直接生成普通 order（totalPrice=秒杀价×数量）→ 支付零侵入；seckill_order 仅 CREATED/CANCELLED。
8. **多角色平台化（M6）**：merchant 表 + product/order 归属列；入驻审核流；归属校验；顾客端只返 ON、管理端全量。
9. **监控（P2-2）**：TraceIdFilter（order=1）生成/透传 X-Trace-Id，finally 清理；deploy/alert.rules.yml 4 条告警。
10. **多实例（P3）**：spring-session-data-redis（Cookie SESSION）；`--scale backend=3`；上传目录需 NFS/OSS 共享。
11. **图片本地化（M3-4/RR-5）**：种子图本地 SVG + `SeedImageInitializer`（启动拷贝，不覆盖真实上传）；三环境代理。

<h3 id="sec512">5.12 前端工程细节</h3>

- **axios 拦截器（utils/request.js）**：baseURL `/api`、withCredentials、timeout 10000；响应 code!==200 → reject(Error(message))；HTTP 401 → 清登录态跳 Login（带 redirect）；HTTP 403 → 仅 reject 不跳转（管理接口被普通用户访问不重定向）；其余透传 serverMessage。

- **utils/format.js**：formatPrice（两位小数）、formatSize、formatTime（YYYY-MM-DD HH:mm:ss）、splitImgs（空格/分号）、firstImg、statusText（8 态中文映射）。

<h2 id="ch6">6. 支付接入</h2>

### 6.1 支付宝沙箱（个人可办、免费）

1. open.alipay.com 个人账号 → 沙箱环境：APPID、网关 `https://openapi.alipaydev.com/gateway.do`、沙箱买家账号、RSA2 密钥。
2. 应用私钥（PKCS8）自留，应用公钥贴沙箱；支付宝公钥由平台生成。
3. 环境变量：`ALIPAY_APP_ID`、`ALIPAY_PRIVATE_KEY`（PEM 内容或路径）、`ALIPAY_PUBLIC_KEY`（验签）、`ALIPAY_NOTIFY_URL`（=`https://your-domain.com/api/pay/alipayNotify`）、`ALIPAY_GATEWAY`（可选）。
4. 联调：`ngrok http 8080` 并同步沙箱回调地址；回调已排除 CSRF。
5. FAQ：普通支付宝 App 扫沙箱码无效（须沙箱版 App+买家账号）；回调 failure=误用应用公钥；上线正式换 APPID/密钥/正式网关，代码不动。

### 6.2 微信支付（需营业执照：企业/个体户）

1. 商户号 + 绑定 AppID + APIv3 密钥（32 位）+ WXCertUtil 证书（serial_no、apiclient_key.pem、apiclient_cert.pem）+ 平台证书（推荐验签）。
2. 环境变量 8 项：`WECHAT_PAY_APPID/MCHID/API_V3_KEY/PRIVATE_KEY_PATH/SERIAL_NO/NOTIFY_URL/PLATFORM_CERT_PATH/API_BASE`；NOTIFY_URL=`https://your-domain.com/api/pay/wechatNotify`。
3. FAQ：模拟支付=变量未配齐；回调验签失败=平台证书不匹配；金额 0=元分换算；订单超时后扫码被拒属预期。私钥仅环境变量注入，NOTIFY_URL 必须 HTTPS。

<h2 id="ch11">11. 常见问题 FAQ</h2>

**Q：登录/注册报 400 或无法登录？** 登录/注册是 form-urlencoded（`userName&pwd`），前端已用 URLSearchParams；curl 用 `-d "userName=...&pwd=..."` 且带 Referer。

**Q：管理端商品列表看不到商品？** 顾客端 `/api/product/page` 只返在售 ON；管理端须用 `/api/admin/product/list`（全量）。商家上架的商品同理在顾客端默认可见（ON）。

**Q：秒杀提示"您已参与过该活动"？** 同一用户对同一活动限抢一次（uk_user_activity 唯一约束兜底），属预期。

**Q：优惠券为什么不能用在多商品结算？** batchAddOrders 逐品拆单，券仅支持单笔订单（整批至多一笔且仅 1 件商品）。

**Q：支付显示模拟？** 未配置支付宝/微信环境变量即回退模拟；配置见第 6 章。

**Q：微信回调验签失败？** 平台证书与商户不匹配；未配平台证书时（fail-closed）直接拒签，属安全设计。

**Q：订单 30 分钟未付自动关闭？** 是（默认 30 分钟，`-Dqinghe.order.expire-minutes` 调整）；秒杀订单超时自动回滚活动库存。

**Q：商家提交入驻后无法操作商品？** 需平台管理员在 `/admin/merchants` 审核通过（ACTIVE）后方可经营。

**Q：文件删不掉 / vite build 报 emptyDir 失败？** 本机 safe-delete 机制 fail-closed，用 `mv` 移出项目或资源管理器手动删除。

**Q：打包报 Unable to rename？** 有 java 进程在跑锁住了 jar，先杀进程再 package。
